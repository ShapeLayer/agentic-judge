# 현재 UI 기능

이 문서는 `ui/app/index.html`과 `ui/app/app.ts`에 구현된 설치형 문제풀이 화면을 설명합니다. `agentic-judge serve --open`으로 실행하며, 서버가 바이너리에 내장한 자원을 제공합니다. 실행 경로와 세션 정책은 [INSTALLATION.md](INSTALLATION.md), 화면 구성은 [UI-DESIGN.md](UI-DESIGN.md), 빌드는 [ui/README.md](../ui/README.md)를 참고합니다.

## 탐색과 문제 조회

앱은 `/` 또는 `/index.html`의 단일 화면입니다. 문제 선택 시 URL을 `#<인코딩된 문제 ID>`로 바꾸며, 초기 로드에서 해당 문제를 복구합니다. 별도 문제·답안·테스트 상세 URL이나 탭 라우터는 없습니다.

왼쪽 목록은 `problems_list`의 이름과 ID를 대상으로 대소문자를 구분하지 않는 검색을 제공합니다. 문제를 선택하면 이름, ID, 시간 제한(ms), 메모리 제한(MiB), `problem_get.ready`에 따른 준비 여부를 표시합니다. 본문은 legend/input/output/notes 중 Markdown이 있는 섹션의 서버 정화 HTML을 표시하고, 예제 입력·출력을 순서대로 보여 줍니다. 수식은 서버가 반환한 MathML로 표시합니다.

## 코드 작성과 초안

기본 에디터는 textarea이며 Tab 키로 공백 4개를 삽입합니다. 언어 목록은 `capabilities.languages`에서 읽으며 초기 언어는 Python이 있으면 Python, 없으면 첫 언어입니다.

입력 즉시 localStorage에 임시 저장하고, 500ms 후 `draft_save`로 서버에 저장합니다. 저장 키는 저장소 루트·워크스페이스·문제·언어로 구분합니다. 문제·언어 전환 전에는 기존 초안을 저장하며, 복구 시 미전송 브라우저 초안을 서버 초안보다 우선합니다. 문제별 선택 언어도 브라우저에 보관합니다. 미전송 초안이 있으면 페이지 종료 경고를 요청합니다.

파일 열기는 브라우저 File API로 텍스트를 읽어 에디터에 넣고 초안으로 저장합니다. 파일 확장자가 설정된 언어 파일명과 일치하면 언어를 선택합니다. 파일 크기는 3 MiB까지이며, JSON 요청은 UTF-8 기준 4 MiB를 초과하면 전송 전에 거부합니다. 파일로 저장은 초안을 저장한 후 `/api/draft-download`에서 다운로드합니다.

워크스페이스가 연결되어 있으면 파일 목록과 상대 경로 입력으로 `workspace_read`를 호출할 수 있습니다. scratch 모드에서는 이 영역과 문제 가져오기를 숨깁니다.

## 제출과 결과

제출은 초안 저장 후 현재 문제·언어·코드를 `submit`에 전달합니다. API는 동기식이며, 처리 중 버튼·입력·선택 요소를 비활성화하고 상태 메시지를 표시합니다. 실패하면 서버 오류를 표시합니다. 제출 실패 시에는 기록을 다시 조회하고 재시도 전에 기록을 확인하도록 안내합니다.

제출 목록은 생성 시간 역순이며 각 `details`의 요약에 verdict·언어·시각을 표시합니다. 펼치면 제출 코드와 테스트별 suite/번호, verdict, 실행 시간, 입력·기대 출력·실행 출력·진단·체커 메시지를 보여 줍니다. 번호가 0인 결과는 컴파일로 표시합니다. 입력과 기대 출력은 제출 기록에 저장된 값을 사용합니다. 제출 완료 후 첫 번째 결과를 펼치며 에디터 코드는 유지합니다.

## 문제 등록과 채점 준비

| 화면 동작 | API와 저장 범위 |
|---|---|
| 문제 만들기 | `problem_create`: ID와 이름 |
| 문제 가져오기 | `problem_import`: 워크스페이스 문서 경로와 ID. 반환 경고를 준비 상태 옆에 표시 |
| 설명 저장 | `statement_set`: legend 섹션 Markdown |
| 정해 저장 | `answer_save`: 언어·코드, expected=AC, main=true. 재생성 오류 표시 |
| 테스트 저장 | `test_put`: general suite, 번호와 입력. 다음 번호는 기존 general 최댓값+1 |
| 새로고침 | 초안 저장 후 문제 목록과 선택 문제·제출 기록 재조회 |

입력·출력·노트 섹션 편집, 예제 편집, validator/generator/checker 설정, 답안 리비전·diff, AI 검증 관리는 현재 화면에 없습니다. 관련 백엔드 도구는 [API-TOOLS.json](API-TOOLS.json)의 HTTP/MCP 인터페이스 명세으로 유지합니다. Monaco, 구문 강조, 목록 정렬·페이지 나누기, 별도 테스트 상세 화면도 현재 구현 범위에 포함되지 않습니다.

## 정적 자원과 접근성

서버는 `/app.js`, `/app.css`, `/tokens.css`를 내장하고 CSP로 스크립트·스타일·API 연결을 동일 출처로 제한합니다. 외부 CDN이나 폰트를 로드하지 않습니다. 본문 정화와 파일 접근 경계는 서버에서 처리합니다.

폼은 label과 기본 HTML 컨트롤을 사용합니다. 문제 검색·목록에는 접근 가능한 이름이 있고, 선택 문제에는 `aria-current`를 표시합니다. 전역 알림은 `role=status`와 `aria-live=polite`, 초안 상태는 `role=status`를 사용합니다. 상세 펼침은 네이티브 details/summary입니다.
