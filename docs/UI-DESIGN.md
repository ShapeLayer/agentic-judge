# 현재 UI 화면 구성

설치형 앱의 실제 HTML과 스타일은 `ui/app/index.html`, `ui/app/app.css`, `ui/styles/tokens.css`입니다. 기능과 API 연결은 [UI-SPEC.md](UI-SPEC.md)를 참고합니다. 이 문서는 구현된 화면을 기준으로 유지합니다.

## 배치

상단에는 브랜드, 워크스페이스 또는 즉석 작성 상태, 새로고침 버튼을 배치합니다. 요청 상태와 오류 알림은 바로 아래에 표시합니다.

본문은 230px 문제 목록과 나머지 작업 영역의 2열입니다. 목록 아래에는 문제 만들기와 워크스페이스 문서 가져오기 폼을 접을 수 있는 영역으로 제공합니다. 문제 미선택 시 사용 안내를 표시합니다.

선택 문제의 헤더에는 이름·제한·ID와 준비 여부를 표시합니다. 아래에는 문제 본문과 문제풀이 영역을 약 1:1.1 비율의 2열로 배치하고 간격은 28px입니다. 풀이 영역은 언어·파일 도구, 워크스페이스 파일 열기, 최소 높이 340px의 코드 textarea, 초안 상태·제출 버튼, 제출 결과 순서입니다. 하단 채점 준비 영역에는 설명·정해·테스트 입력 폼을 둡니다.

## 색상과 글꼴

색상과 글꼴은 `tokens.css`의 CSS 변수를 사용합니다. 앱은 시스템 `prefers-color-scheme`을 따라 라이트·다크 팔레트를 적용합니다. 화면에 수동 테마 전환 버튼이나 테마 저장 로직은 없습니다.

기본 글꼴은 시스템 sans-serif, 코드 입력은 시스템 monospace 스택입니다. 외부 폰트 다운로드는 없습니다. 앱 본문은 14px/1.6, h1은 22px, h2는 16px입니다. 토큰 파일에 남은 공통 크기 선언보다 `app.css`의 실제 적용값을 기준으로 합니다.

경계선과 보조 배경으로 영역을 구분하고 선택 문제와 제출 버튼에는 강조색을 사용합니다. 버튼과 입력의 모서리는 5px입니다. 오류는 전역 알림의 텍스트로 표시하며, verdict는 제출 결과에 문자열로 표시합니다.

## 반응형과 상호작용

- 1000px 이하: 문제 본문과 풀이를 세로로 배치하고 목록 폭을 190px로 줄입니다.
- 640px 이하: 목록과 작업 영역도 세로로 배치합니다. 목록 높이는 최대 180px이며 스크롤할 수 있습니다. 작업 영역 패딩은 18px입니다.
- 입력·출력·소스는 공백을 보존하는 pre에 표시하고 긴 내용은 스크롤합니다. 본문 이미지는 영역 너비를 넘지 않습니다.
- 키보드 포커스는 강조색 2px 외곽선으로 표시합니다. 요청 중 비활성화한 컨트롤은 불투명도 0.5와 대기 커서로 표시합니다.
- 제출 결과와 채점 준비는 네이티브 details/summary로 펼칩니다. Web Components나 별도 컴포넌트 라이브러리를 사용하지 않습니다.
